# Gaco Cosmetics – Codex Documentation (README)

## Mục đích

Đây là bộ tài liệu chính thức để Codex xây dựng website **Gaco Cosmetics**.

Website phải:

- React + Vite
- Tailwind CSS
- Framer Motion
- Lenis Smooth Scroll
- React Router
- i18next (VI/EN)
- Dark Mode
- Responsive
- Deploy Vercel
- Sau khi deploy có thể nhúng vào Google Sites.

## Quy tắc bắt buộc

- Không Bootstrap.
- Không jQuery.
- Không inline CSS.
- Mọi text phải dùng i18next.
- Mọi component phải tái sử dụng được.
- Hero cao khoảng 90–92vh.
- Animation dùng Framer Motion.
- Scroll dùng Lenis.
- Không được sao chép trực tiếp giao diện Cocoon, chỉ lấy cảm hứng về ngôn ngữ thiết kế.
